# Command: /entscheidung

Erstellt eine harte Entscheidungsvorlage mit Ampel für eine oder mehrere Ideen.

## Ablauf
1. Top-Ideen aus docs/top-ideen.md lesen
2. Scores und Risiken aufbereiten
3. Klare Entscheidungsvorlage ausgeben
4. Erst nach Freigabe in docs/entscheidungslog.md schreiben

## Ausgabe-Struktur

# Entscheidungsvorlage

| Idee | Score | Ampel | Status | Empfehlung | Nächster Schritt |
|---|---:|---|---|---|---|

Für jede Idee:
- Stärkstes Argument dafür
- Stärkstes Argument dagegen
- Was muss zuerst bewiesen werden?
- Entscheidung: TESTEN / SCHÄRFEN / ZURÜCKSTELLEN / VERWERFEN

## Pflichtfrage
"Ich würde die Entscheidung in docs/entscheidungslog.md festhalten. Soll ich das ausführen? Ja/Nein."
