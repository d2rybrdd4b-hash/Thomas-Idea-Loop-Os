# Command: /thema-setzen

Thomas kann Themenfelder und Einschränkungen für den nächsten Loop setzen.

## Verarbeitet Eingaben wie
- nur B2B / nur B2C
- nur lokal / nur DACH / europaweit / weltweit
- nur digital / nur ohne App / nur schnelle Umsätze
- neue Geschäftsfelder / unbekannte Nischen
- keine sensiblen Daten / keine Hotels / keine Plattformen
- Maschinenbau / Tourismus / Wohnmobil / Familie / Prozessoptimierung

## Ablauf
1. Eingabe aufnehmen
2. docs/input-themen.md aktualisieren (erst nach Freigabe)
3. Neue Einschränkungen für nächsten Loop dokumentieren

## Pflichtfrage vor Datei-Änderung
"Ich würde docs/input-themen.md mit folgenden Einstellungen aktualisieren: [Zusammenfassung]. Soll ich das ausführen? Ja/Nein."

## Ausgabe
- Zusammenfassung der gesetzten Themen und Einschränkungen
- Hinweis auf geänderte Pflichtmischung (falls von 30/40/30 abgewichen wird)
- Warnung wenn weniger als 20 % neue Perspektiven gesetzt wurden
